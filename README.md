# Portfólio pessoal acessível

Modelo de portfólio responsivo feito com HTML, CSS e JavaScript, preparado para personalização e publicação no GitHub Pages.

## Recursos de acessibilidade incluídos

- Link para pular diretamente ao conteúdo principal.
- Navegação por teclado e foco visível.
- Controles para diminuir, restaurar e aumentar o tamanho do texto.
- Tema claro, tema escuro e alto contraste.
- Avisos acessíveis para leitores de tela ao alterar opções.
- Estrutura semântica, rótulos, textos alternativos quando aplicáveis e layout responsivo.
- Respeito à preferência de movimento reduzido do sistema.

Os recursos são uma base de boas práticas, não uma certificação automática de conformidade. Teste com teclado, leitor de tela e diferentes dispositivos.

## Personalize antes de publicar

1. Abra `index.html`.
2. Substitua `Seu Nome`, cargo, biografia, formação e contatos.
3. Troque os links genéricos dos projetos pelos links reais. Remova projetos que não sejam seus.
4. Em `css/style.css`, edite as variáveis do início para personalizar as cores.
5. Teste o site localmente e confira os três modos de acessibilidade.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `css/`, `js/` e `README.md` para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Selecione a publicação a partir da branch `main` e da pasta `/ (root)`.
5. Salve, aguarde a publicação e teste o endereço fornecido.

## Atenção

- Não publique dados pessoais que não deseja tornar públicos.
- Os links de projetos e redes sociais são exemplos e devem ser atualizados.
- Um portfólio pode conter links para currículo, mas adicione um arquivo PDF apenas quando tiver preparado uma versão própria.
